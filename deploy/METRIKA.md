# Яндекс.Метрика

Счётчик: **112667049**. Заменяет старый счётчик, работает сразу на публичных страницах nsk-rent.ru и www.nsk-rent.ru. Админка и превью исключены.

В Яндекс.Метрике откройте этот счётчик → Настройки → Цели → Добавить цель. Для каждой выберите тип **JavaScript-событие**:

| Название | Идентификатор | Когда отправляется |
| --- | --- | --- |
| Звонок | `call` | Нажатие любой ссылки телефона; не подтверждает состоявшийся разговор |
| Бронь | `booking` | Успешное сохранение новой брони, независимо от дальнейшего результата оплаты |
| Вход в кабинет | `login` | Успешная авторизация паролем, SMS, восстановлением пароля или автоматический вход после регистрации/подтверждения SMS при оформлении |

Код отправки событий добавлен на сайт. Создание целей в аккаунте Яндекса требует доступа владельца; из этого проекта такого доступа нет. После обновления VPS и создания целей проверьте их в отчёте «Конверсии». Блокировщики могут препятствовать сбору. Персональные данные в параметры целей не передаются.
