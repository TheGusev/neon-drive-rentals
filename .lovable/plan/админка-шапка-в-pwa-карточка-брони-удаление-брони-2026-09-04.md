# Админка: шапка в PWA, карточка брони, удаление брони

## 1. Шапка админки не кликабельна в PWA

В PWA-режиме (standalone) статус-бар iPhone накладывается на верхнюю панель админки: сейчас она закреплена вплотную к верху экрана без запаса под «чёлку», поэтому часть шапки скрыта и по ней нельзя попасть пальцем.

- Добавить в шапку админки безопасный отступ сверху (как уже сделано в публичной части), чтобы содержимое опускалось ниже статус-бара.
- Панель фильтров/заголовка страницы, которая липнет под шапкой, сдвинуть на ту же величину, чтобы не было наложения.

## 2. Полная информация по брони при нажатии

Сейчас клик по карточке брони в `/admin/bookings` показывает только всплывающее уведомление «Просмотр брони N».

Вместо этого открывается выезжающая панель с полной информацией:

- Автомобиль: фото, марка/модель, год, номер.
- Клиент: имя, телефон, e-mail (если есть).
- Даты и время выдачи и возврата, количество суток, адрес выдачи.
- Сумма аренды, статус оплаты, статус договора.
- Маршрут аренды: оплата → договор → ключи выданы → возврат, с датами и ответственным.
- Действия прямо из панели: выдать ключи, принять возврат, сменить статус, удалить бронь.

## 3. Удалённая бронь исчезает везде

Сейчас бронь можно только отменить — она остаётся в списках и в личном кабинете клиента.

- Добавить настоящее удаление брони в админке (с подтверждением).
- После удаления бронь пропадает из списка админки, из личного кабинета клиента (текущая аренда и история) и из занятых дат автомобиля — авто снова становится свободным на эти даты.

## Техническая часть

- `AdminHeader.tsx`: `pt-[max(env(safe-area-inset-top),0)]` и авто-высота вместо фиксированной `h-16`; `PageHeader.tsx` — `top` пересчитать через ту же переменную (CSS-переменная `--admin-header-h` в `styles.css`).
- Новый компонент `AdminBookingDetailSheet.tsx` (shadcn `Sheet`), подключается в `_admin.admin.bookings.tsx` вместо `toast` в `onView`; данные берутся из уже загруженной строки `getBookingsAdmin` (при необходимости расширить выборку полями клиента и `pickupAddress`).
- Server function `deleteBooking` в `src/lib/bookings.functions.ts` + `deleteBookingInDb` в `bookingsRepo.server.ts` (админ-гейт как у остальных админ-функций), удаление платёжных ссылок/каскад по `booking_id`.
- После удаления — инвалидация `["admin","bookings"]`, `["bookings"]`, `["cars"]`, `["me"]`.
