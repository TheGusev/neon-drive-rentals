# Убрать сдвиг блоков при скролле на главной

## Что меняем

Все анимации на главной, которые двигают элементы по вертикали/горизонтали при прокрутке, заменяем на спокойное появление через прозрачность. Ничего не «подпрыгивает» и не сдвигается — размеры и позиции блоков фиксированы с первого кадра.

1. Плитки «Гаража» и бокового NFS-меню: вместо выезда снизу со сжатием — плавное проявление на месте (без translate/scale).
2. Активная машина в карусели: подсветка только цветом рамки, свечением и прозрачностью — без увеличения/уменьшения карточек, поэтому лента не «дышит» при горизонтальном скролле.
3. Блоки с эффектом появления при прокрутке (SEO-плитки, секции сцены): только прозрачность, без подъёма на 18px.
4. Плавающая кнопка меню: при скролле вниз просто исчезает, при скролле вверх — появляется, без вылета вверх.
5. Постоянное «покачивание» (float-slow) и пульсация кнопки меню отключаются на главной, чтобы не было визуального дрожания.

Наведение мышью (hover) остаётся с лёгким подъёмом карточек — это не связано со скроллом и layout shift не вызывает.

## Технические детали

- `src/styles.css`:
  - `@keyframes garage-in` → только `opacity: 0 → 1`; убрать `translateY`/`scale`.
  - `.reveal` → `transform: none`, `.reveal-in` → анимация только по прозрачности (новый keyframe `fade-in-soft`).
  - `.garage-card[data-active="true"|"false"]` → убрать `transform: scale(...)`, оставить `opacity`, `filter`, `border-color`, `box-shadow`; `transition` без `transform`.
  - `.nfs-slide-in` → без `translateX`, только прозрачность.
  - `.float-slow`, `.menu-pulse` — отключить (animation: none) либо заменить на изменение свечения без transform.
- `src/components/home/HomeControls.tsx`: убрать `data-[hidden=true]:-translate-y-24` и `translate-y-0`, оставить только `opacity` + `transition-opacity`.
- Блок `@media (prefers-reduced-motion: reduce)` оставляем как есть — он уже совпадает с новым поведением.
- Проверка: мобильный вьюпорт 393px и десктоп — прокрутка главной сверху донизу без смещения блоков.
