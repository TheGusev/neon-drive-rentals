# Подсказки на плитках гаража

## Что делаем

К каждой карточке авто в блоке «Гараж выбора» добавляем всплывающую подсказку с названием модели и 3-4 короткими преимуществами, чтобы было понятно, что за машина, до клика.

Содержимое подсказки:
- Заголовок: марка, модель, год и цвет
- Чипы преимуществ: расход (л/100 км), коробка, мест, класс/пункт «правый руль», лимит пробега
- Цена за сутки по выбранному тарифу и статус: «Свободна» или «Занято до дд.мм»
- Подсказка «Нажмите, чтобы посмотреть и забронировать»

Поведение:
- Десктоп: появление при наведении и при фокусе с клавиатуры, задержка ~150 мс, плавное появление.
- Мобильные (нет hover): подсказка автоматически показывается у активной (центральной) карточки карусели — она же подсвечена. При скролле подсказка переезжает на новую активную карточку без дёрганий.
- Подсказка не перехватывает клики и не мешает свайпу карусели.

Плитки преимуществ сбоку (NFS-меню) тоже получают короткую подсказку с расшифровкой (например, «Пункт выдачи → Новосибирск, ул. Доватора, 11, без доставки»).

## Технические детали

- Использовать существующий `src/components/ui/tooltip.tsx` (Radix). Обернуть содержимое `GarageShowcase` в `TooltipProvider delayDuration={150}`.
- `GarageCard`: `TooltipTrigger asChild` на кнопке карточки, `TooltipContent side="top"` с `pointer-events-none`. Для мобильного авто-показа использовать контролируемый `open`: `open = active && isCoarsePointer` (определять через `matchMedia("(hover: none)")` в `useEffect`), иначе неконтролируемый hover/focus.
- Данные брать из уже подключённых `car` и `useHomeBooking` (тариф, даты) + `isCarAvailable` / `nextBusyUntil` — новых источников данных не добавляем.
- `NfsSideMenu`: обернуть плитки в `Tooltip` с полем `hint` в массиве `items`; на мобильных (horizontal) — только по нажатию/фокусу, без автопоказа.
- Учитывать `prefers-reduced-motion`: без анимации появления.
