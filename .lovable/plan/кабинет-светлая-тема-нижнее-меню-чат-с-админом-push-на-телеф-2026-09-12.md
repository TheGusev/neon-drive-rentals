# Кабинет: светлая тема, нижнее меню, чат с админом, push на телефон

## 1. Push-оповещения админу — где они живут

Push уже устроены правильно: события (бронь, оплата, возврат, отмена, просрочка, новый клиент) пишутся в вашу базу на вашем сервере, и оттуда же сервер сам отправляет уведомление на телефон. Никаких сторонних сервисов вроде Firebase или Telegram не нужно, всё внутри вашего VPS.

Что доделаем, чтобы это реально заработало:
- Проверим, что при брони, оплате, возврате и просрочке событие создаётся (сейчас вызовы расставлены во всех этих местах).
- В настройках админки — понятная кнопка «Включить оповещения на телефон» и кнопка «Отправить тест».
- Подсказка для iPhone: уведомления приходят только если сайт добавлен на экран «Домой» и открыт оттуда (требование Apple).
- Нужны два ключа (VAPID) в секретах сервера — без них push молча выключен, а колокольчик в админке всё равно работает. Я подготовлю команду генерации.

## 2. Светлая тема

- Кабинет всегда светлый: переключатель луны из кабинета убираем, шапка, содержимое, подвал и нижнее меню — один светлый тон, как в админке.
- Каталог: если включена светлая тема каталога, светлыми становятся и шапка с подвалом — сейчас шапка остаётся тёмной (скрин 1).
- Пройдём по всем блокам кабинета и каталога и уберём остатки тёмных цветов: карточки, поля дат, бейджи, кнопки.
- Админку проверим отдельно: она остаётся светлой везде, включая всплывающие окна и формы.

## 3. Нижнее меню в кабинете

- Меню становится только про кабинет: Аренды, Сообщения, Документы, Профиль. Пунктов «Главная» и «Каталог» больше нет — из кабинета случайно не выкинет.
- Меню всегда видно: фиксировано внизу, не прячется при скролле, с отступом под системную полосу iPhone.
- Активная вкладка подсвечивается, содержимое кабинета не перекрывается меню.

## 4. Сообщения (переписка с админом)

- Вкладка «Сообщения» открывает настоящий чат клиента с администратором.
- Клиент видит историю, пишет сообщение, получает ответ; непрочитанные помечены значком на вкладке.
- В админке — раздел «Сообщения» со списком диалогов, последним сообщением и ответом в один клик; можно открыть чат прямо из карточки клиента.
- Новое сообщение от клиента создаёт оповещение админу и push на телефон.
- Обновление автоматическое (опрос раз в 10–15 секунд), без перезагрузки страницы.

## Техническая часть

- Миграция `021_messages.sql`: таблица `messages` (id, client_id, sender `client|admin`, body, created_at, read_at) с индексами по client_id/created_at; таблица не трогает существующие данные.
- `src/lib/messagesRepo.server.ts` — список диалогов для админа, лента по клиенту, отправка, пометка прочитанного.
- `src/lib/messages.functions.ts` — клиентские функции через сессию клиента (`clientSession.server`) и админские через `requireAdmin`.
- Новое сообщение клиента вызывает `notifyAdmins({ kind: "message" })` → запись в `admin_notifications` + web push.
- UI: `src/components/profile/MessagesBlock.tsx` (чат в кабинете), `src/routes/_admin.admin.messages.tsx` + пункт в `AdminTabBar`.
- Тема: `useProfileTheme` упрощаем до фиксированной `clean-light` для `/profile`; `PublicLayout` красит шапку/подвал темой каталога, когда включён светлый каталог (общий контекст темы вместо локального класса на секции).
- `BottomNav.tsx` переписывается на разделы кабинета с якорями/вкладками внутри `/profile`, `fixed` без логики скрытия.
- Push: `src/routes/_admin.admin.settings.tsx` получает блок подписки (`getPushPublicKey`, `savePushSubscription`, `sendTestPush` уже есть).

## Что понадобится от вас

Ключи VAPID в секретах сервера (сгенерирую команду) и добавление сайта на экран «Домой» на iPhone для проверки push.
