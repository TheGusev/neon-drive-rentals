# Мгновенный переход к авто + спокойные анимации

## Предпрогрузка выбранного авто
1. При наведении мышью, касании или фокусе с клавиатуры на плитке гаража заранее готовим страницу `/cars/<id>`: подгружаем маршрут и данные машины ещё до клика.
2. Одновременно прогреваем изображение авто (главное фото галереи), чтобы страница и быстрый просмотр открывались без «мигания» пустой картинки.
3. Прогрев выполняется один раз на машину и с небольшой задержкой (~80 мс), чтобы случайный проезд курсором по карусели не грузил всё подряд.
4. То же поведение — для кнопки «глаз» (быстрый просмотр) и для активной центральной плитки на мобильных: её данные прогреваются автоматически, ещё до касания.

## Уважение к «уменьшенному движению»
1. Если в системе включено «Reduce Motion», кнопка меню перестаёт улетать вверх и пульсировать: она просто мягко меняет прозрачность или остаётся на месте.
2. Плавный скролл карусели гаража заменяется мгновенным, подсветки-«свипы», пульсации и появления плиток отключаются.
3. Открытие модалок и шторок — без сдвигов и масштабирования, только простое появление.
4. Логика (что видно, что скрыто, порядок элементов) не меняется — меняется только характер анимации.

## Технические детали
- Новый хук `src/hooks/usePrefetchCar.ts`: `router.preloadRoute({ to: "/cars/$carId", params })` + `new Image().src = car.image`, с `Set` уже прогретых id и таймером задержки; вызовы из `onMouseEnter`, `onFocus`, `onTouchStart` в `GarageCard`, плюс `useEffect` на смену `active` при coarse pointer.
- `GarageShowcase.tsx`: передаём хендлеры на `Link` и на кнопку быстрого просмотра; `preload="intent"` остаётся.
- Новый хук `src/hooks/useReducedMotion.ts` (matchMedia `prefers-reduced-motion: reduce`, SSR-безопасный) для JS-анимаций: в `useHideOnScroll` при reduce не выставляем `data-hidden` (кнопка всегда видна), в `GarageShowcase` `scrollByCards` использует `behavior: "auto"`, вход плиток без stagger.
- `src/styles.css`: расширяем существующий блок `@media (prefers-reduced-motion: reduce)` — отключаем `menu-pulse`, transform-переходы кнопки меню (`[data-hidden]` только по opacity), анимации Radix `data-[state]` для Dialog/Sheet/Tooltip.
- Никаких изменений в данных, ценах и бизнес-логике бронирования.
