# Точечный фикс: метатеги, дубль контента главной, robots.txt

## Что проверено сейчас (факты)

- **Метатеги главной — в порядке.** В HTML-выводе `/` ровно один `<title>` и ровно один `<meta name="description">` (непустой, 158 символов). Тегов `robots: noindex` / `nosnippet` на главной нет.
- **robots.txt — есть и разрешает индексацию.** Отдаётся серверным маршрутом `src/routes/robots[.]txt.ts` по `/robots.txt` (код 200), начинается с `User-agent: *` / `Allow: /`, содержит `Sitemap: https://nsk-rent.ru/sitemap.xml`. Строки `Disallow: /` нет — только служебные разделы (`/admin`, `/booking/`, `/payment/`, `/profile` и т.п.). Отдельный файл в `public/` не нужен и создаваться не будет (он бы конфликтовал с маршрутом).
- **Дубль контента подтверждён.** В `src/routes/index.tsx` десктопная и мобильная версии главной рендерятся обе, а прячутся только через CSS (`hidden md:block` / `md:hidden`). В HTML это даёт два `<h1>` «Аренда японских кей-каров в Новосибирске», два блока быстрого бронирования, два гаража и два списка авто. Гидратация тут ни при чём — дубль есть уже в серверном HTML.

## Что делаю

Оставляю ровно один вариант главной в HTML — визуально ничего не меняется.

1. Определяю тип устройства на сервере по заголовку `User-Agent` запроса (лёгкая серверная функция, только чтение заголовка).
2. `src/routes/index.tsx` через loader получает флаг `isMobile` и рендерит **только один** компонент: `HomeMobile` или `HomeDesktop`. Никаких `hidden md:block` дублей.
3. После гидратации проверяю реальную ширину экрана (`matchMedia('(max-width: 767px)')`) и, если серверная догадка не совпала (например, планшет или десктоп с мобильным UA), переключаю вариант на клиенте. Пользователь видит корректную версию, а поисковик — один комплект контента и один `<h1>`.
4. Метатеги и robots.txt не трогаю — они уже корректны; в отчёте приведу их финальное содержимое.

## Технические детали

- Новый файл `src/lib/device.functions.ts`: `createServerFn({ method: "GET" })` → читает `user-agent` из `getRequest()`, возвращает `{ isMobile: boolean }`. Публичный, без авторизации — безопасен для SSR и пререндера.
- `src/routes/index.tsx`: `loader` вызывает эту функцию, `HomeShell` берёт значение через `Route.useLoaderData()` и хук с `matchMedia` для клиентской коррекции.
- Затрагиваемые файлы: `src/routes/index.tsx` + один новый хелпер. Бронирование, БД, админка и остальные страницы не меняются.
