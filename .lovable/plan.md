
## Что делаем

Полноценная админ-панель (`/admin` + разделы) в светлой деловой теме. Оставляю существующий `AdminLayout` с боковым меню, обновляю только шапку и меняю stub-контент на реальные страницы. Работаем на моках.

## Общие компоненты (`src/components/admin/`)

- `AdminHeader.tsx` — обновление шапки в `AdminLayout`: логотип + «ПАНЕЛЬ УПРАВЛЕНИЯ», справа колокольчик уведомлений (Popover с 2–3 мок-событиями), профиль администратора (Avatar + имя, DropdownMenu). Плюс `SidebarTrigger`.
- `PageHeader.tsx` — заголовок раздела + слот под действия/фильтры.
- `StatCard.tsx` — KPI-карточка (иконка, заголовок, значение, дельта).
- `StatusDot.tsx` — цветной индикатор для статусов (free/busy/wash/maintenance).
- `PaymentStatusBadge.tsx` — бейдж статуса оплаты.

Расширю `src/mocks/`:
- `clients.ts`: добавлю поля `email`, `blacklisted`, `createdAt`, `lastBooking` (в тип `Client`).
- `payments.ts` (новый): 8–10 платежей с датой, клиентом, авто, суммой, методом, статусом.
- `notifications.ts` (новый): 3 мок-уведомления.
- `cars.ts`: добавлю поле `status: 'free' | 'busy' | 'washing' | 'maintenance'` для CRUD-таблицы автопарка.

Обновлю `src/types/domain.ts` соответствующими полями (обратно совместимо: новые поля опциональны там, где могут ломать).

## Страницы

### `/admin` — дашборд
- Верхний ряд: кнопка `+ Создать договор аренды` (full-width, primary) → toast «Форма скоро появится».
- 4 KPI-карточки (StatCard) из `dashboardStats`: брони сегодня (+дельта), выручка сегодня (+дельта, руб), автопарк, клиенты.
- Блок «Статус автомобилей»: 4 строки с `StatusDot` (зелёный/красный/синий/оранжевый) и цифрами, плюс мини-прогресс-бар.
- «Активные брони»: `Table` с фото авто, клиентом, датами, суммой, `PaymentStatusBadge`. Данные — `bookings` со статусом `active|paid|pending`, join c `cars`/`clients`.
- Двухколоночный низ: shadcn `Calendar` с подсветкой занятых дат (из bookings) и «Последние клиенты» — компактный список 4 клиентов с рейтингом (звезда).
- «Быстрые действия»: сетка 5 кнопок с иконками (новый клиент, добавить авто, календарь мойки, отчёты, настройки) → toast-заглушки, кроме «настройки» → Link на `/admin/settings`.

### `/admin/cars` — автопарк (CRUD)
- `PageHeader` с кнопкой «+ Добавить авто» (toast).
- `Table`: фото (мини), марка/модель, год, госномер, класс, КПП, цена/сутки, статус (`StatusDot` + текст, `Select`-заглушка), действия (`Edit`/`Trash` — toast).
- Фильтры сверху: поиск (Input), статус (Select).

### `/admin/bookings` — заявки
- `PageHeader`.
- Фильтры: поиск, статус (`Tabs`: все / pending / paid / active / completed / cancelled).
- `Table`: № брони, авто, клиент, даты, сумма, статус (`PaymentStatusBadge`), действия (просмотр — toast).

### `/admin/clients` — CRM + чёрный список
- `PageHeader` + «+ Новый клиент» (toast).
- `Tabs`: «Все» / «Чёрный список».
- `Table`: имя, телефон, email, кол-во заказов, рейтинг (звезда), статус (Switch «в чёрном списке» — локальный state, toast).

### `/admin/finance` — платежи + экспорт
- `PageHeader` с кнопкой «Экспорт в Excel» (используем `xlsx` через `bun add xlsx` — генерируем `payments.xlsx` на клиенте).
- Итоговый ряд KPI: всего платежей, оборот, средний чек.
- `Table`: дата, № брони, клиент, авто, сумма, метод (Card/СБП), статус.

### `/admin/settings` — оставляю StubPage (не в скоупе промта).

## Технические детали

- Используем существующие shadcn `Table`, `Tabs`, `Select`, `Input`, `Switch`, `Popover`, `DropdownMenu`, `Avatar`, `Badge`, `Calendar`, `Button`.
- Тема — `clean-light` уже включена в `AdminLayout`; все цвета через существующие semantic-токены (никаких hex). Для статус-точек — палитра tailwind (`bg-emerald-500`, `bg-rose-500`, `bg-sky-500`, `bg-amber-500`) внутри `StatusDot`.
- Экспорт Excel: `bun add xlsx`, функция `exportPayments()` в `src/lib/exportExcel.ts`; вызывается по клику. Скачивается через Blob URL.
- Все CRUD-действия — заглушки с `toast`, без изменения бизнес-логики публичных страниц.
- Никаких изменений роутинга (файлы уже созданы), только контент компонентов.
