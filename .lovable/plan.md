## Цель

Главная (десктоп, NFS-неон) — компактно, всё читаемо, ни одна буква не «съедается» фоном. Добавить SEO-блоки плиткой с анимированным появлением сбоку (как левое меню NFS), сменяющиеся фоны с эффектом «свет фар» на тексте, и анимированный градиент в буквах NSK-RENT.

## Что меняем на десктопной главной (`src/components/home/HomeStage.tsx` + `src/styles.css`)

### 1. Ротатор фонов «под светом фар»

- Сменяющиеся хиро-фоны: `hero-drive.jpg` + 2 новых генерируемых кадра (ночной токийский туннель, неоновый гараж-паркинг).
- Слой-«фары»: два широких конических градиента, движущихся справа-налево на 8с. Там где «луч» проходит по тексту — текст локально светлеет (через `mix-blend-mode: screen` на слое-луче поверх текста + `backdrop-filter: brightness()` под текстовым блоком).
- Под текстовой колонкой — постоянная «читающая подложка»: узкий вертикальный градиент `bg-gradient-to-r from-background/85 via-background/55 to-transparent` шириной ~520px. Это гарантирует читаемость **всех** букв независимо от кадра. Никаких полупрозрачных абзацев без подложки.
- Смена кадра — кроссфейд 1.2с каждые 7с; параллакс `ken-burns` сохраняем.

### 2. Анимированный логотип NSK-RENT

- Текст с `background-clip: text` и движущимся градиентом (голубой → циан → белый → голубой), анимация `hue-shift` 6с + периодический «свип» бликом (белая полоса под углом, 4с). 
- Убираем текущее «глитч-мерцание», из-за которого буквы визуально пропадают. Оставляем только мягкий neon-glow (`text-shadow` в 3 слоя) — стабильный, без flicker.

### 3. Левое «NFS-меню» — плитка блоков с анимированным появлением

Слева, поверх хиро, узкая колонка (~300px) с 5–6 плитками, каждая появляется каскадом (`translateX(-24px) + fade`, задержки 80мс). Плитки — компактные, стеклянные (`backdrop-blur`, тонкая неон-рамка), с иконкой + 1 строкой:

1. Парк из 8 JDM кей-каров
2. Правый руль · Япония
3. Аренда от 1 800 ₽/сутки
4. Доставка по Новосибирску
5. Онлайн-договор за 3 минуты
6. Поддержка 24/7

Hover — подсветка левой границы неоном + сдвиг на 4px вправо (как выбор пункта в NFS).

### 4. Компактный SEO-блок (плиткой, не мешает хиро)

Внизу хиро (в пределах одного экрана 1440×900) — горизонтальная лента из 4 SEO-плиток с якорями-ссылками на существующие разделы. Каждая плитка = h3 + короткий абзац с ключевыми фразами:

- «Аренда авто в Новосибирске» → `/cars`
- «Кей-кары из Японии» → `/cars?class=econom`
- «Аренда без залога от 1 800 ₽» → `/cars`
- «Доставка авто в аэропорт Толмачёво» → `/cars?location=airport`

Плитки анимируются каскадом при появлении в viewport (IntersectionObserver + `rise-in`).

Дополнительно, для SEO без визуального шума:
- Один видимый `<h1>` = «Аренда японских кей-каров в Новосибирске — NSK-RENT» (сейчас `<h1>` = «NSK-RENT», это плохо для SEO).
- Подпись под логотипом «NSK-RENT» превращаем в `<p>` (не h1).
- Скрытый визуально, но доступный `<section aria-label="О сервисе">` с 2–3 SEO-абзацами (класс `sr-only` НЕ используем — используем `absolute -z-10 opacity-0 pointer-events-none` с реальным текстом, чтобы Googlebot индексировал; либо оставляем видимым внутри SEO-плиток. Предпочитаю второе — всё в видимых плитках, без cloaking).

### 5. Читаемость всего текста хиро

- Все текстовые блоки хиро оборачиваем в контейнер с фоновой подложкой (`bg-background/70 backdrop-blur-md` + `rounded-2xl` + `px-6 py-5`). Проверяю: заголовок, подзаголовок, строка «12 авто свободно», кнопки CTA, чипы «Честные цены/Поддержка/Онлайн/JDM» — у каждой чипы уже своя карточка, оставляем, но повышаем контраст текста до `text-foreground` (сейчас часть уходит в muted и теряется на светлых кадрах фона).
- Заголовок NSK-RENT получает `filter: drop-shadow(0 4px 24px rgba(0,0,0,.7))` — читается на любом кадре.

### 6. Компактность (без скролла на 1440×900)

Реорганизация в 3 колонки внутри хиро:

```text
┌──────────┬──────────────────────────┬────────────────┐
│ NFS-меню │ Логотип + подзаг + CTA   │ (пусто, фары)  │
│ 6 плиток │ + строка доступности     │                │
├──────────┴──────────────────────────┴────────────────┤
│  Лента «Популярные модели» (как сейчас, full-bleed)  │
├──────────────────────────────────────────────────────┤
│  SEO-плитки (4 шт, компактные, h≈96px)               │
└──────────────────────────────────────────────────────┘
```

Всё влезает в 900px: hero-зона ~440px, карусель ~260px, SEO-полоса ~110px, отступы.
