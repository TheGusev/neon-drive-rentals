# Плавная анимация блока «Гараж выбора»

Цель: сделать вход плиток, подсветку активной машины и скролл карусели заметно мягче, без «дёрганий» при переключении темы.

## Что изменится визуально

1. **Вход плиток и карточек** — при первом появлении блока в зоне видимости плитки преимуществ и карточки авто всплывают по очереди (лёгкий подъём + проявление, задержка ~60 мс на элемент). Появление запускается один раз, повторный скролл его не перезапускает.
2. **Подсветка активной машины** — активная карточка не просто меняет прозрачность: она плавно увеличивается, получает мягкое неоновое свечение по контуру и приглушённый «свет фар», а соседние — слегка уменьшаются и уходят в размытие. Переход между состояниями идёт по единой кривой, без скачка.
3. **Микро-скролл** — карусель получает инерционное поведение: доводка к ближайшей карточке после свайпа, плавная прокрутка стрелками, «резинка» на краях. Индикатор-полоса под каруселью двигается сглаженно (rAF), а не рывками на каждое событие скролла.
4. **Без дёрганий при смене темы** — на время переключения темы анимации/переходы цвета кратко отключаются, поэтому карточки не «моргают» и не проигрывают вход заново.

## Технические детали

- `src/styles.css`
  - добавить `@keyframes garage-in` и класс `.garage-in` с `animation-delay` через CSS-переменную `--i` (stagger без JS-таймеров);
  - переработать `.garage-card`: единая кривая `cubic-bezier(0.22,1,0.36,1)`, состояния `[data-active="true"]` (scale 1.03, неоновая тень, `garage-sweep` в медленном лупе) и `[data-active="false"]` (scale 0.97, opacity 0.6, лёгкий blur);
  - `.garage-strip { scroll-behavior: smooth; overscroll-behavior-x: contain; scroll-snap-type: x mandatory; }`;
  - глобальный «глушитель»: `html.theme-switching *, html.theme-switching *::before, html.theme-switching *::after { transition: none !important; animation-play-state: paused !important; }`;
  - расширить блок `prefers-reduced-motion`: отключить `garage-in`, sweep-луп и scale, оставить только смену прозрачности.
- `src/components/home/GarageShowcase.tsx`
  - вычисление `active`/`progress` перевести на `requestAnimationFrame`-throttle вместо прямого пересчёта в `onScroll`;
  - индикатор позиции анимировать через `transform: translateX()` вместо `margin-left` (композитинг на GPU, без layout);
  - на карточку передать `data-active`, `style={{ "--i": index }}` и класс `.garage-in`;
  - запуск входа — через `IntersectionObserver` с флагом «уже проигран».
- `src/components/home/NfsSideMenu.tsx` — те же `--i` и `.garage-in` для плиток, чтобы вход блока читался как одна волна.
- `src/components/layout/ThemeProvider.tsx` — при смене темы вешать на `<html>` класс `theme-switching` и снимать его в следующем кадре (~200 мс), чтобы переходы цветов не конфликтовали с анимациями гаража.

## Проверка

- Скриншоты главной на мобильном (393px) и десктопе (1440px) в тёмной и светлой темах.
- Переключение темы прямо на блоке «Гараж» — карточки не мигают и не проигрывают вход повторно.
- Прокрутка карусели стрелками и свайпом: индикатор движется плавно, активная карточка меняется без рывка.
