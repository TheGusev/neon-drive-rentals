## Что не так сейчас
- Главная разбита на 3 длинных блока (hero, преимущества, карусель) — нужен скролл, ощущение «пустой лендинг».
- Все карточки авто используют один и тот же `heroCar` — визуально скучно и обманчиво.
- Анимаций почти нет — статичный текст, статичный фон, никакой атмосферы «драйва».
- На мобилке та же вертикаль, только уже — тоже длинно и пресно.

## Цель
Главная (ПК и мобилка) — **один экран без скролла** (100vh/100svh), кинематографичная, с ощущением ночного драйва и явным CTA «взять авто».

## Десктоп (public-dark, NFS-неон) — bento в один экран

Layout: CSS grid `h-screen`, 3 колонки × 2 ряда, без прокрутки.

```text
┌─────────────────────────────┬───────────────────┐
│  HERO (заголовок + subline) │  QUICK BOOKING    │
│  анимированные неон-полосы  │  (компактная      │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ │   форма)          │
├──────┬──────┬──────┬────────┤                   │
│ BEN1 │ BEN2 │ BEN3 │  BEN4  │                   │
├──────┴──────┴──────┴────────┼───────────────────┤
│  POPULAR MODELS — карусель  │  STATS / CTA      │
│  автопрокрутка, hover-tilt  │  «Забрать сегодня»│
└─────────────────────────────┴───────────────────┘
```

Ключевое:
- Преимущества сжимаются в 4 плоские мини-плитки (иконка + короткий заголовок), одна строка.
- Карусель моделей — уменьшенные карточки с автоскроллом (`embla autoplay`), паузой на hover, tilt-эффектом.
- Правая колонка бронирования — sticky-виджет + мини-CTA «Забрать сегодня» со счётчиком свободных авто.
- Header фиксированный, компактный (h-14), футер убираем с главной (переносим только на внутренние).

Анимации:
- Hero: неоновые линии-стримеры (SVG stroke-dasharray анимация) слева-направо, лёгкий параллакс машины на mouse move.
- Заголовок `NSK-RENT` — glitch/flicker неон (2s cycle) + текст-shimmer.
- Bento-плитки — staggered fade-in при монтировании (`animate-fade-in` с delay).
- Карточки моделей — hover: scale + neon-glow + подсветка колёс (уже есть на фото).
- Кнопка «Найти авто» — pulse-glow, стрелка сдвигается на hover.
- Фоновая машина — медленный ken-burns zoom (20s), поверх — движущиеся световые полосы.

## Мобилка (clean-light) — компактный single-view

Тоже цель — один экран (100svh) без скролла до CTA:

```text
┌──────────────────────┐
│  Header (лого + меню)│  56px
├──────────────────────┤
│  HERO-карточка       │
│  фото авто + gradient│  ~38svh
│  NSK-RENT (крупно)   │
│  1 строка sub        │
├──────────────────────┤
│  Быстрая форма       │  ~34svh
│  (место, даты в 1    │
│   ряд, CTA)          │
├──────────────────────┤
│  Chips: 4 преим-ва   │  горизонт. скролл, ~10svh
├──────────────────────┤
│  «Популярные» →      │  ~12svh, snap-scroll мини-карточки
└──────────────────────┘
```

- Преимущества — горизонтальный chips-скролл с иконкой + 1 словом.
- Популярные — мини-карточки 140×90 с snap-scroll (быстро листаются пальцем).
- Softer анимации: fade-in-up на монтировании, ripple на кнопке, лёгкий shine по CTA.
- Никакого neon — синий акцент primary, но живой (кнопка с градиентом + shadow).
