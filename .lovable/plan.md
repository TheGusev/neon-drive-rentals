# Убрать всплывающие подсказки на главной

## Проблема

На мобильной главной подсказки к плиткам «Гаража» открываются автоматически у активной машины. Radix позиционирует их поверх контента, и при скролле они «прыгают» вверх, накладываются друг на друга (на скрине видно две одинаковые карточки Honda N-WGN) и перекрывают блоки меню.

## Что делаем

1. Полностью убрать авто-открытие подсказки для активной машины на сенсорных устройствах — на мобильных подсказок не будет вообще.
2. Убрать подсказки у плиток бокового NFS-меню на мобильных (там они только мешают, вся информация уже видна в плитке).
3. На десктопе подсказки остаются по наведению/фокусу — как сейчас.
4. Ничего больше на главной не меняем: карусель, плитки, кнопка меню, анимации остаются как есть.

## Технические детали

- `src/components/home/GarageShowcase.tsx`: убрать `useCoarsePointer` + `{...(coarse ? { open: active } : {})}`; на coarse-указателе рендерить карточку без обёртки `Tooltip`.
- `src/components/home/NfsSideMenu.tsx`: аналогично — на сенсорных устройствах рендерить плитку без `Tooltip`.
- Хук `useCoarsePointer` остаётся, меняется только его применение.
- Проверка: мобильный вьюпорт 393px, прокрутка главной — никаких плавающих панелей поверх контента.
