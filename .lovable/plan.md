# Синхронизация плитки гаража со страницей авто

## Что сейчас
Клик по карточке в «Гараже» открывает модальное окно быстрого просмотра. Активная плитка (та, что в центре карусели) и содержимое модалки не связаны с адресом страницы, а переход на карточку авто доступен только через кнопку внутри модалки.

## Что сделаем
1. Клик по плитке сразу открывает страницу выбранной машины `/cars/<id>` — без промежуточного окна.
2. Плитка становится настоящей ссылкой: работает Cmd/Ctrl+клик, открытие в новой вкладке, предзагрузка при наведении.
3. Активная (центральная) плитка карусели остаётся синхронной: она подсвечена, её подсказка открыта, и переход ведёт именно на неё.
4. Быстрый просмотр сохраняем как отдельное действие: маленькая кнопка «Быстрый просмотр» в углу плитки открывает модалку, не уводя со страницы. Внутри модалки кнопка «Подробнее» ведёт на ту же страницу авто.
5. На странице авто добавим корректный возврат: кнопка «Назад» возвращает на главную/каталог, как и раньше.

## Технические детали
- `src/components/home/GarageShowcase.tsx`: карточку `GarageCard` переводим с `button + onOpen` на `Link to="/cars/$carId" params={{ carId: car.id }}` с `preload="intent"`; отдельная кнопка-иконка внутри вызывает `setQuickCar(car)` с `preventDefault/stopPropagation`.
- Активный индекс (`active`) продолжает вычисляться по скроллу; он управляет только подсветкой и открытым tooltip (`open={active}` на coarse pointer) — навигация берёт id из самой карточки, поэтому рассинхрона быть не может.
- `CarQuickView` не меняем по структуре, ссылка «Подробнее» уже указывает на `/cars/$carId`.
- Не трогаем данные, цены и логику бронирования.
